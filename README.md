# Card Game War 

Eine Umsetzung des klassischen Kartenspiels **War** (Krieg) in **JavaScript**, gespielt im Browser.

## Spielregeln

- Ein Deck mit 52 Karten wird gemischt und gleichmäßig auf zwei Spieler verteilt.
- In jeder Runde decken beide Spieler ihre oberste Karte auf.
- Die höhere Karte gewinnt, und der Spieler nimmt beide Karten.
- Bei Gleichstand kommt es zum **War**: Jeder legt verdeckte Karten ab und deckt dann eine weitere auf – die höhere Karte gewinnt alle Karten auf dem Tisch.
- Wer alle Karten sammelt, gewinnt das Spiel.

## Technologien

- HTML
- CSS
- JavaScript
